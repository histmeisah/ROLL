# Bandit-REINFORCE++


## 动机

赌博机问题是强化学习中的经典问题类别，通常涉及单状态、一步决策，且不存在状态转移。在大语言模型（LLM）数学推理的后训练场景中，模型接收一个问题提示 $y$ 并需要生成答案 $x$。我观察到，我们可以很自然地将 $y$ 视为状态，将答案的正确性视为奖励。由于每个问题求解过程涉及生成一个完整的解决方案轨迹，而没有有意义的中间状态转移，这个问题结构更接近于上下文赌博机（contextual bandit）设置，而非序列化的马尔可夫决策过程（MDP）。

当前用于LLM推理任务的方法要么使用Best-of-N采样（贪婪地利用最高奖励轨迹），要么使用原始REINFORCE++（随机选择单个轨迹进行策略更新）。这些方法存在样本效率低下的问题，并且缺乏平衡探索与利用的原则性机制。

## 提出的方法

我提出通过双层优化框架将上下文赌博机算法与REINFORCE++整合起来。在外层循环中，我将提示词选择建模为上下文赌博机问题，其中上下文是问题的嵌入表示 $\phi(y) \in \mathbb{R}^d$，臂（arms）是 $K$ 个不同的提示词模板（例如："直接求解"、"逐步思考"、"提供详细推理"），奖励是生成解决方案的准确率。我使用LinUCB算法，该算法将上下文相关的奖励建模为 $\mathbb{E}[r|y,p_i] = \theta_i^\top \phi(y)$，并通过以下方式选择提示词：

$$p^* = \arg\max_{p_i} \{ \theta_i^\top \phi(y) + \alpha \sqrt{\phi(y)^\top A_i^{-1} \phi(y)} \}$$

这自然地平衡了对不确定提示词的探索和对每种问题类型历史上成功提示词的利用。

在内层循环中，给定选定的提示词 $p^*$，我应用标准的REINFORCE++来训练LLM：采样多条轨迹，评估其正确性，并使用高奖励轨迹更新策略。在每个训练问题之后，我更新赌博机的统计信息，以逐步学习哪些提示词对哪些问题类型效果最好。

在实现方面，我将使用ROLL框架（https://github.com/alibaba/ROLL/tree/main/roll）并在Qwen2.5-3B-Instruct或Qwen2.5-7B-Instruct模型上进行训练。

## 评估计划

我计划在数学推理基准测试上评估我的方法，包括AIME 2024和2025、MATH-500以及GSM8K。这些数据集提供可验证的真实答案，使我能够计算精确的二元奖励，而无需奖励模型。我将与原始REINFORCE++（随机轨迹选择）、Best-of-N采样和固定提示词基线进行比较。我的主要评估指标将是Pass@1准确率和样本效率。我还将对提示词模板数量 $K$ 和探索参数 $\alpha$ 进行消融研究，以了解它们对性能的影响。
